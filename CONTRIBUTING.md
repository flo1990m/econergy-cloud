# Contribuer

Les contributions et retours sont les bienvenus. Avant de proposer une modification :

- vérifie que le comportement n'est pas déjà documenté comme une limite de l'API ;
- n'ajoute pas de jeton, code OAuth, mot de passe, identifiant de compte ou donnée personnelle ;
- utilise les routes documentées par Econergy et n'invente pas de commande non confirmée ;
- conserve les validations de plages de températures et de programmation ;
- ne renvoie jamais automatiquement une commande lorsque son résultat est incertain.

Pour un changement important, ouvre d'abord une issue afin de discuter de l'approche.
